# Contributing

Contributing guidelines we as the Eclipse Team want to hold ourselves to.
These apply to all repositories inside the eclipse-energy organization.

The full guidelines live at <https://eclipse-energy.github.io/.github/>

- [Contributor guidelines](https://eclipse-energy.github.io/.github/contributor)
- [Reviewer guidelines](https://eclipse-energy.github.io/.github/reviewer)
- [AI guidelines](https://eclipse-energy.github.io/.github/ai)

## The essentials

- Branches: `USER_SHORTNAME/GH_ISSUE my awesome branch`, e.g. `gert/gh-1 create contributing guidelines` (use `noissue` if there is no issue).
- Commits start with the issue number, e.g. `GH-1:`, and are short and descriptive.
- Keep PRs small and focused on one change / issue.
- Make sure CI passes and review your own PR (Draft PR) before requesting review.
- Respond to review comments and keep the discussion on the PR.

The sources are in [`docs/`](docs). Changes to the guidelines go through a pull request like any other change.
